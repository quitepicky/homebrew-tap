# Quite Picky Homebrew tap

Install [Considered](https://github.com/quitepicky/considered), the repository
policy and decision documentation tool:

```sh
brew install --cask quitepicky/tap/considered
```

The cask supports macOS and Linux on Intel/AMD 64-bit and ARM64. It installs both
`considered` and `considered-scc`. Use a current Homebrew version with Linux cask
support when installing on Linux.

The first cask packages the existing v0.1.10 GitHub Release. All four archive
checksums were verified against the published `checksums.txt`. Future stable
releases are generated and committed here by Considered's GoReleaser workflow.

Project source and issue reports: https://github.com/quitepicky/considered
